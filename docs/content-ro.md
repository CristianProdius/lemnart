## 10. FAQ

**Section title:**
```
Expertiză Tehnică
```

**Subheading:**
```
Întrebări Frecvente
```

### Q1: Din ce material este confecționată masca?
```
Utilizăm exclusiv MDF Premium certificat, cu densitate ridicată, vopsit prin tehnologie poliuretanică în 4 straturi. Acest proces asigură rezistență totală la căldura radiatorului fără a emite substanțe toxice.
```

### Q2: Cât timp durează execuția proiectului?
```
Termenul standard pentru o comandă personalizată este de 10-14 zile lucrătoare. Această perioadă include proiectarea 3D, tăierea CNC de mare precizie și cele 48 de ore necesare pentru uscarea controlată a vopselei.
```

### Q3: Este afectată eficiența termică a camerei?
```
Dimpotrivă. Măștile noastre sunt proiectate pentru a favoriza convecția naturală prin fantele inferioare și superioare. Fluxul de aer este direcționat strategic spre centrul camerei, optimizând confortul.
```

### Q4: Oferiți livrare și montaj profesionist?
```
Livrăm și montăm în regim propriu în Chișinău și suburbii. Pentru restul republicii, asigurăm transport securizat prin curierat rapid, cu instrucțiuni detaliate de auto-montaj.
```
